Refactoring release. meetingsync keeps its job (MacWhisper export to a meeting note in Notion with a local model), but the code is split into packages, the file handling is crash-safe, and the security checks are stricter. It is a major version because some behavior and defaults changed.

## Breaking changes / what you must do when upgrading

| Change | What you must do |
| --- | --- |
| `meetingsync -check` exits 1 if any line shows ✗ and on config, token or Keychain errors (before: 0 on ✗). ADR [0012](../adr/0012-check-exit-code.md) | Scripts that rely on exit 0 must adapt. launchd is not affected. |
| Default `my_name` is now `Max` (was `Mark`) | Set `my_name` explicitly in your config. |
| New keys `my_role` (default empty) and `example_name` (default `Alex`) replace the hard-coded role and example name in the LLM prompt. ADR [0009](../adr/0009-prompt-personalization.md) | Set both to keep the previous prompt wording. |
| New optional key `notion.notes_properties.source` (for example `Quelle`). With it, no duplicate page is created after an unclear create failure. ADR [0004](../adr/0004-ledger-states-and-crash-behavior.md) | Add a text column with this name to the Notes database and set the key. Without the key the guard is off. |
| Every note with a to-do for you gets the review reason "Enthält To-dos für dich – bitte Zuordnung und Fälligkeit prüfen". ADR [0010](../adr/0010-pruefen-flag-for-todos.md) | Only notes with at least one to-do assigned to you (`fuer_mich`) are flagged; others are unchanged. |
| A note with more than 1000 Notion blocks (transcript not counted) is not retried and goes to `_fehler` at once | Move the files back by hand if you want to retry. |
| `-file` without `-dry-run` writes ledger entries and waits for the export-folder lock (it does not move the file). ADR [0013](../adr/0013-file-ledger-and-folder-lock.md) | Restart the service after installing; an old running service has no folder lock. |
| `llm.api_key` can come from the Keychain (`llm.api_key_keychain_service`). A Keychain error aborts start. ADR [0014](../adr/0014-llm-api-key-keychain.md) | Optional. |
| `llm.base_url` must point to this Mac (`localhost`, `127.0.0.1`, `::1`); `notion.base_url` must be https. ADR [0007](../adr/0007-llm-base-url-loopback-only.md), [0008](../adr/0008-notion-https-only.md) | Start aborts otherwise; check your config. |
| `llm.timeout_minutes` below 1 is clamped to 1 (before: no timeout) | None, unless you set 0. |
| The build needs `golang.org/x/sys` (new dependency, ADR [0005](../adr/0005-golang-x-sys-for-atomic-rename.md)); Linux builds are not supported | Build on macOS. |

After installing:

1. Rebuild: `go build -o ~/bin/meetingsync .`
2. Restart the launchd service.
3. Run `meetingsync -check` after every config change. It also hints if the `source` column is missing.

## Other changes

Full list: [changelog](../changelog.md).

- Security hardening: loopback-only LLM URL, https-only Notion URL, no redirects, response size limits, no symlink following, private file modes, absolute tool paths with a minimal environment, escaped IDs in Notion paths, config values out of error messages, real Notion IDs removed from the example configs (history rewritten 2026-11-09, ADR [0011](../adr/0011-clean-git-history.md)).
- Robustness and performance: crash-safe ledger states, a move never overwrites a file, failed archive moves retried, gaps in a note recorded, files read only when needed, bounded maps, a 10 s timeout for the model list in `-check`, fixed date parsing for `DD.MM.YYYY_HH-MM`.
- Structure and docs: `internal/*` packages (ADR [0015](../adr/0015-package-split.md), [0006](../adr/0006-interfaces-and-dependency-injection.md)), golden tests, CI, Makefile, `docs/architecture.md`, `docs/testing.md`.

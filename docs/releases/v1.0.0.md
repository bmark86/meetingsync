First release. meetingsync turns MacWhisper exports into a meeting note in Notion, with tasks and a project link. It uses a local model in LM Studio. Everything runs on the Mac. The raw transcript does not leave it (exception: `include_transcript`).

## Features

- Detects transcript and summary by file extension and content (`.srt`/`.vtt` are always transcripts).
- Pairs a transcript with a summary (same name stem, otherwise the closest file in time).
- Reads the date from the file name (MacWhisper format and `TT.MM.JJJJ`, that is DD.MM.YYYY).
- Condenses long transcripts section by section (chunking).
- Creates a note (Notes), tasks and the link to an active project in Notion.
- Archives to `_archiv/JJJJ-MM` (by year and month); a ledger prevents double processing.
- Retry with backoff. After `max_attempts` (default 10) the file goes to `_fehler` (the error folder).
- `-dry-run`, `-check` and `-once` for testing.
- Config as YAML (an existing JSON config still works).
- Notion token from the Keychain.
- Runs as a service with launchd.

## Requirements

- macOS and Go 1.22+
- LM Studio with a loaded model (tested: `google/gemma-4-31b-qat`, context length at least 32768)
- A Notion integration, connected to the Second Brain page
- MacWhisper

## Installation

There are no binaries. You build from source:

```bash
git clone https://github.com/bmark86/meetingsync.git && cd meetingsync
go build -o ~/bin/meetingsync .
mkdir -p ~/.config/meetingsync && cp config.example.yaml ~/.config/meetingsync/config.yaml
~/bin/meetingsync -check   # or meetingsync, if ~/bin is in your PATH
```

Token in the Keychain, config values, LM Studio settings and launchd: see the README, section "Setup".

## MacWhisper export

The combined `.srt` (speaker + time marks) is recommended. Set `my_speaker_label` to `"Microphone"`.

## Known limitations

- `meetingsync -check` exits with 0 even when a line shows ✗ (for example LM Studio). Read the output.
- `-file` without `-dry-run` writes no ledger entry and does not move the file. If it is in `watch_dir`, the next run creates a second note.
- If LM Studio is off for longer than `max_attempts` allows (about 95 minutes with the default values), the files go to `_fehler`. You must move them back into the export folder by hand.
- The error counters are not saved to disk.
- Error messages for `orphan_summary_action` and `timezone` print the value (`%q`).
- Build with Go 1.26.10 or newer. Older toolchains have known weaknesses in the standard library (among others crypto/tls, net/http).
